# jadi ini
Proyek ini dibuat untuk menganalisis data customer menggunakan Python.

## Library yang dedek gunakan:
* Pandas
* Matplotlib
* Seaborn

## ketik diterminal:
1. Pastikan Python terinstall.
2. Jalankan `pip install pandas matplotlib seaborn`.
3. Ketik `py dashboard.py` di terminal.

# dan ini jii

Proyek ini dibuat untuk mengambil data saham JII (Jakarta Islamic Index) secara otomatis dari Yahoo Finance menggunakan bahasa Python.

## Library yang dedek gunakan:
* Pandas
* yfinance

## Ketik di terminal:

### 1. Install Library
Jalankan perintah ini:
`pip install pandas yfinance`

### 2. Jalankan Program
Ketik `py jii.py` di terminal.
